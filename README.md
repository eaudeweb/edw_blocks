# EDW Blocks

Provides a collection of custom blocks like _Hero Banner_ block and _Search_ block

## Installation

1. Add the following snippet to the `repositories` section of your `composer.json` file:
```
{
    "type": "git",
    "url": "https://github.com/eaudeweb/edw_blocks.git"
}
```

2. Run
```composer require eaudeweb/edw_blocks:^1.0```

3. Enable the module:
``drush en edw_blocks``
